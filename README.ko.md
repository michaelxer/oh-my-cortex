# oh-my-cortex

**OpenCode를 위한 인지 운영 체제.**

oh-my-cortex (OMX)는 OpenCode를 단순한 코딩 도구가 아닌, 의사결정, 전략, 커뮤니케이션, 리스크 관리까지 아우르는 사고 파트너로 변환하는 멀티 에이전트 플러그인입니다.

OMX를 설치하고 `deepwork`를 입력하세요. 당신의 가정에 도전하고, 민감한 도메인에 적응하며, 의사결정을 구조화하고, 정밀하게 실행하는 11명의 전문 에이전트 팀을 얻게 됩니다.

---

## 왜 OMX인가?

대부분의 AI 도구는 당신이 말하는 모든 것에 동의합니다. OMX는 반박합니다.

대부분의 AI 도구는 코드만 작성합니다. OMX는 사고를 돕습니다.

대부분의 AI 도구는 모든 것에 하나의 모델을 사용합니다. OMX는 적절한 두뇌를 적절한 작업에 자동으로 라우팅합니다.

## OMX의 차별점

### Challenge Engine

에이전트는 단순히 실행하지 않습니다. 약한 추론이 나쁜 결정이 되기 전에 도전합니다.

부드러운 지적부터 완전한 적대적 리뷰까지, 4단계의 푸시백:

| 레벨 | 이름 | 동작 |
|---|---|---|
| 1 | **Nudge** | 하나의 가정이나 개선점을 지적 (항상 활성) |
| 2 | **Probe** | 트레이드오프, 리스크, 사각지대, 더 나은 옵션을 제시 |
| 3 | **Mirror** | 회피, 약한 논리, 기회비용을 지적하고 처방을 제시 |
| 4 | **Red Team** | 경쟁자, 회의론자, 투자자, 규제기관 관점에서 공격 |

`/challenge 3`으로 수동 설정하거나, "솔직히 말해줘" 또는 "내가 뭘 놓치고 있어?"라고 말하면 자동으로 활성화됩니다.

### Domain Lenses

OMX는 대화가 민감한 영역에 진입했음을 감지하고 자동으로 조정합니다:

| 도메인 | 변경 사항 |
|---|---|
| **Health** | 비진단적. 전문가 상담 권장. 근거 기반 정보만 제공. |
| **Legal** | 보수적. 정보와 조언을 구분. 관할권 인식. |
| **Financial** | 데이터 기반. 위험 허용도 명시. 정보와 금융 조언을 분리. |
| **Security** | 트리아지 우선. 방어만. 증거 보전. 전문가에게 에스컬레이션. |
| **Political** | 이해관계자 인식. 체면 유지. 프로토콜 준수. |

`/lens security`로 수동 활성화하거나, OMX가 컨텍스트에서 자동 감지하도록 할 수 있습니다.

### 코드를 넘어서

OMX는 다른 코딩 도구가 처리할 수 없는 것을 처리합니다:

- **비즈니스 전략** — 경쟁 분석, M&A 평가, 시장 진입 계획
- **민감한 커뮤니케이션** — 청중 인식, 레버리지 보존, 스크린샷 대비를 고려한 메시지 작성
- **리스크 평가** — 위협 트리아지, 위기 계획, 인시던트 대응
- **리서치 종합** — 다중 소스 삼각측량, 증거 검토, 경영진 요약
- **의사결정 지원** — 트레이드오프와 권장사항을 포함한 구조화된 옵션 A/B/C 분석
- **코칭** — 스킬 개발, 성찰 연습, 건설적 도전

### 구조화된 추론

모든 OMX 에이전트는 불확실성이 중요할 때 확신도 라벨을 사용합니다:

- **Confirmed** — 검증됨, 출처 있음, 직접 알고 있음
- **Likely** — 충분히 뒷받침되는 추론
- **Possible** — 그럴듯하지만 미검증
- **Speculative** — 가설에 불과

거짓된 확신 없음. 근거 없는 주장 없음. 에이전트가 모를 때는 모른다고 말합니다.

## OMX 팀

### 프라이머리 에이전트 (Tab으로 선택 가능)

| 에이전트 | 역할 |
|---|---|
| **Chief** | 메인 오케스트레이터. 모든 요청을 목표, 이해관계, 리스크, 긴급도로 분류. 전문가에게 위임. 약한 가정에 도전. 작업을 완료까지 추진. |
| **Founder** | 자율적 딥 워커. 지시가 아닌 목표를 제공. 컨텍스트를 탐색하고, 패턴을 조사하며, 엔드투엔드로 실행. |

### 서브에이전트 (Chief가 자동으로 호출)

| 에이전트 | 역할 |
|---|---|
| **Thinker** | 전 도메인 컨설턴트. 아키텍처, 비즈니스 전략, 리스크, 건강, 법률, 금융, 정치 분석. 읽기 전용 — 순수 추론, 액션 없음. |
| **Researcher** | 지식 탐색기. 문서, 오픈소스 예제, 표준, 모범 사례. |
| **Tracker** | 코드베이스 탐색기. 빠른 파일 검색, 패턴 탐색, 로컬 컨텍스트 매핑. |
| **Planner** | 전략적 인터뷰어. 질문이 먼저, 계획이 나중. 반복적 질문을 통해 상세한 작업 계획 생성. |
| **Reviewer** | 갭 파인더. 숨겨진 가정, 모호함, 누락된 수락 기준, 이해관계자 사각지대를 포착. |
| **Critic** | 품질 게이트. 참조가 검증되고 수락 기준이 구체적일 때만 승인. |
| **Lead** | 프로젝트 매니저. Worker에게 구현 작업을 위임하고, 학습을 축적하며, 완료를 검증. |
| **Worker** | 작업 실행자. 집중적, 규율적, 범위 한정. 재위임 불가. |
| **Spotter** | 비주얼 분석가. 스크린샷, 다이어그램, PDF, 이미지. |

## 명령어

| 명령어 | 동작 |
|---|---|
| `deepwork` 또는 `dw` | 풀 활성화 — 모든 에이전트, 최대 강도, 자율 실행 |
| `/dw-loop` | Cortex 루프 — 100% 완료될 때까지 작업 계속 |
| `/challenge [1-4]` | 챌린지 레벨 설정 (1=nudge, 2=probe, 3=mirror, 4=red-team) |
| `/checkpoint` | 대화 요약 강제 — 결정사항, 가정, 액션 아이템 |
| `/lens [domain]` | 도메인 렌즈 활성화 (health, legal, financial, security, political) |
| `/decide` | 구조화된 의사결정 프레임워크 — 옵션, 트레이드오프, 리스크, 권장사항 |
| `/start-work` | Planner가 생성한 계획에서 실행 |
| `/cancel-cortex` | Cortex 루프 중지 |

## 설치

### 빠른 시작

OpenCode 세션에 다음을 붙여넣으세요:

```
Install and configure oh-my-cortex by following the instructions here:
https://raw.githubusercontent.com/michaelxer/oh-my-cortex/refs/heads/dev/docs/guide/installation.md
```

### 수동 설치

```bash
# OpenCode 설정에 추가
# ~/.config/opencode/opencode.jsonc
{
  "plugin": ["oh-my-cortex"]
}

# OpenCode 재시작 — 플러그인이 npm에서 자동 설치됩니다
# 또는 수동으로 설치:
cd ~/.config/opencode
npm install oh-my-cortex
```

### 인터랙티브 설정

```bash
bunx oh-my-cortex install
```

인스톨러는 사용 가능한 AI 프로바이더를 확인하고 각 에이전트에 가장 강력한 모델을 자동으로 매칭합니다. 어떤 모델이든 작동합니다 — OMX는 당신의 환경에 적응합니다.
